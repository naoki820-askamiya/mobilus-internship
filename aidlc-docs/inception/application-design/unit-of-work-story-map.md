## Phase 1 (フロントエンド) でカバーされるストーリー

フロントエンド先行で実装するストーリー（モックデータ使用）:

- **US-001**: チャット開始 — チャット画面UI、メッセージ入力
- **US-002**: メッセージ送受信 — メッセージ表示UI（モック応答）
- **US-003**: チャット終了 — 終了ボタンUI
- **US-006**: ログイン — ログインフォームUI（モック認証）
- **US-007**: 問い合わせ一覧 — テーブルUI（モックデータ、優先順表示）
- **US-008**: 問い合わせ担当取得 — 「担当する」ボタンUI
- **US-009**: チャット対応 — チャット詳細画面UI
- **US-010**: 会話履歴参照 — 履歴表示UI（モックデータ）
- **US-011**: ログアウト — ログアウトボタンUI
- **US-012**: オペレータ追加 — 追加フォームUI（モック応答）
- **US-013**: オペレータ一覧・削除 — 一覧テーブルUI（モックデータ）
- **US-014**: BOT事前質問 — 選択肢・サイズ入力UI
- **US-015**: 推定待ち時間表示 — 待ち時間数値と時系列グラフ
- **US-016**: オペレータ稼働状態 — ナビゲーションの稼働/離席切替
- **US-017**: サマリーボード — 日付選択、KPI、時間帯グラフ

## Phase 2 (バックエンド) でカバーされるストーリー

バックエンド実装で完成するストーリー:

- **US-001**: チャット開始 — BOT開始APIで問い合わせ作成、WebSocket接続
- **US-002**: メッセージ送受信 — WebSocketメッセージング、DB保存
- **US-003**: チャット終了 — WebSocket切断処理
- **US-004**: セッションタイムアウト — タイムアウト検知
- **US-005**: タブ閉じ終了 — WebSocket切断検知
- **US-006**: ログイン — 認証API、セッション管理
- **US-007**: 問い合わせ一覧 — 未完了優先順API、完了済み最新50件API
- **US-008**: 問い合わせ担当取得 — 担当割り当てAPI（排他制御、BOT中は不可）
- **US-009**: チャット対応 — オペレータWebSocket接続（認証・権限確認付き）
- **US-010**: 会話履歴参照 — メッセージ取得API（BOT履歴を含む）
- **US-011**: ログアウト — ログアウトAPI、セッション破棄
- **US-012**: オペレータ追加 — オペレータ作成API、パスワード自動生成
- **US-013**: オペレータ一覧・削除 — 一覧取得API、削除API
- **US-014**: BOT事前質問 — 開始/回答API、状態遷移、料金計算
- **US-015**: 推定待ち時間表示 — 現在値算出API、時系列モックAPI
- **US-016**: オペレータ稼働状態 — 状態更新API、待ち時間の稼働人数への反映
- **US-017**: サマリーボード — 日次集計API
