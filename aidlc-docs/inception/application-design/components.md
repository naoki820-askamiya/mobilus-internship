# コンポーネント定義

## フロントエンドコンポーネント

### FE-001: エンドユーザ問い合わせ画面
| 項目 | 内容 |
|------|------|
| コンポーネント名 | EndUserInquiry |
| 目的 | エンドユーザが待ち時間を確認し、BOT事前質問・オペレータとチャットする画面 |
| 責務 | チャット開始前の推定待ち時間表示、チャットUI表示、メッセージ送受信、セッション管理、WebSocket接続管理 |
| ルート | `/` |

**主要UIコンポーネント:**
- `WaitTimeChart` — 時間帯別待ち時間グラフ（入口フェーズ）
- `ChatWindow` — メッセージ一覧表示
- `MessageInput` — メッセージ入力・送信
- `ConnectionStatus` — 接続状態表示
- `EndButton` — チャット終了ボタン

---

### FE-002: オペレータログイン画面
| 項目 | 内容 |
|------|------|
| コンポーネント名 | OperatorLogin |
| 目的 | オペレータがID/PWでログインする画面 |
| 責務 | 認証フォーム表示、ログインリクエスト送信、エラー表示 |
| ルート | `/operator/login` |

**主要UIコンポーネント:**
- `LoginForm` — ID/PW入力フォーム
- `ErrorMessage` — ログインエラー表示

---

### FE-003: 問い合わせ一覧画面
| 項目 | 内容 |
|------|------|
| コンポーネント名 | InquiryList |
| 目的 | すべての問い合わせをステータス付きで一覧表示する画面 |
| 責務 | 問い合わせ一覧取得・表示、ステータス表示、ページング、担当取得操作 |
| ルート | `/operator/inquiries` |

**主要UIコンポーネント:**
- `InquiryTable` — 問い合わせ一覧テーブル
- `StatusBadge` — ステータス表示（担当者未決定/自分の担当/自分の担当外）
- `AssignButton` — 「担当する」ボタン
- `Pagination` — ページング

---

### FE-004: 問い合わせ詳細（チャット）画面
| 項目 | 内容 |
|------|------|
| コンポーネント名 | InquiryDetail |
| 目的 | 担当する問い合わせのチャット対応・履歴閲覧画面 |
| 責務 | チャット表示、メッセージ送受信（担当者のみ）、会話履歴表示 |
| ルート | `/operator/inquiries/:id` |

**主要UIコンポーネント:**
- `ChatWindow` — メッセージ一覧表示
- `MessageInput` — メッセージ入力・送信（担当者のみ有効）
- `InquiryInfo` — 問い合わせ情報ヘッダー

---

### FE-005: 共通レイアウト・認証管理
| 項目 | 内容 |
|------|------|
| コンポーネント名 | AppShell |
| 目的 | アプリ全体のレイアウト、ルーティング、認証状態管理 |
| 責務 | ルーティング管理、認証ガード、ナビゲーション、コンテキスト提供 |

**主要UIコンポーネント:**
- `OperatorNav` — オペレータ用ナビゲーション
- `AuthProvider` — 認証状態コンテキスト
- `ProtectedRoute` — 認証ガード付きルート

---

## バックエンドコンポーネント

### BE-001: 認証モジュール (Auth)
| 項目 | 内容 |
|------|------|
| コンポーネント名 | auth |
| 目的 | オペレータのログイン/ログアウト、セッション管理 |
| 責務 | パスワード検証、セッション作成・破棄、認証ミドルウェア |
| レイヤー | Router → Service → Repository |

---

### BE-002: 問い合わせ管理モジュール (Inquiry)
| 項目 | 内容 |
|------|------|
| コンポーネント名 | inquiry |
| 目的 | 問い合わせの作成、一覧取得、担当割り当て、ステータス管理 |
| 責務 | 問い合わせCRUD、担当者割り当て（排他制御付き）、ページング |
| レイヤー | Router → Service → Repository |

---

### BE-003: チャットモジュール (Chat)
| 項目 | 内容 |
|------|------|
| コンポーネント名 | chat |
| 目的 | リアルタイムメッセージ送受信、メッセージ永続化 |
| 責務 | WebSocket接続管理、メッセージブロードキャスト、メッセージ保存・取得 |
| レイヤー | WebSocket Handler → Service → Repository |

---

### BE-004: WebSocket接続管理 (Connection Manager)
| 項目 | 内容 |
|------|------|
| コンポーネント名 | connection_manager |
| 目的 | WebSocket接続のインメモリ管理 |
| 責務 | 接続登録・削除、問い合わせ単位の接続グループ管理、切断検知 |
| レイヤー | インフラ層（サービスから利用される） |

---

### BE-005: データベース (Database)
| 項目 | 内容 |
|------|------|
| コンポーネント名 | database |
| 目的 | SQLiteデータベース接続・マイグレーション管理 |
| 責務 | DB接続管理、テーブル作成、マイグレーション |
| レイヤー | インフラ層 |
