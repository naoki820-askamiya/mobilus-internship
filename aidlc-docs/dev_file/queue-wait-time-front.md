## 確定したapi仕様

### 1. 現在の待ち時間取得

- メソッド・エンドポイント: `GET /api/wait-time`
- 送信データ: なし
- 目的: 現在の推定待ち時間とデータ取得時刻を返す
- フロントエンドの取得間隔: 1分

バックエンド内部の計算（仮実装）:

`estimated_wait_minutes = ceil(待機人数 × 5 / (オペレーター数 × 2))`

対応可能なオペレーターがいない場合、`estimated_wait_minutes` は `null` とする。

レスポンス（200）:

```json
{
  "estimated_wait_minutes": 8,
  "updated_at": "2026-08-17 18:30:00"
}
```

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `estimated_wait_minutes` | `number \| null` | 推定待ち時間（分）。対応可能なオペレーターがいない場合は `null` |
| `updated_at` | `string` | このレスポンスを計算した時刻（JST） |

`estimated_wait_minutes` が `null` の場合、フロントエンドには「対応できるオペレーターがいません」と表示する。

`null` のレスポンス例:

```json
{
  "estimated_wait_minutes": null,
  "updated_at": "2026-08-17 18:30:00"
}
```

### 2. 待ち時間時系列（グラフ用）

- メソッド・エンドポイント: `GET /api/wait-time/hourly`
- 送信データ: なし
- 目的: 過去の営業時間中に記録された、任意の時間ごとの待ち時間の傾向を取得する
- 営業時間の判定、集計期間の選定および返却対象データの抽出はバックエンドが行う
- フロントエンドは前日実績や過去1週間の平均など、バックエンドの集計期間に依存しない
- 営業時間が日付をまたぐ運用は行わない
- フロントエンドは画面表示時に1回取得し、表示中は再取得しない
- データ件数および時間間隔: 可変

レスポンス（200）:

```json
{
  "updated_at": "2026-08-17 18:30:00",
  "items": [
    {
      "time": "2026-08-16 10:00:00",
      "estimated_wait_minutes": 3
    },
    {
      "time": "2026-08-16 12:30:00",
      "estimated_wait_minutes": 5
    },
    {
      "time": "2026-08-16 17:00:00",
      "estimated_wait_minutes": 12
    }
  ]
}
```

| フィールド | 型 | 説明 |
| --- | --- | --- |
| `updated_at` | `string` | レスポンス生成時刻。データの鮮度表示に使用する |
| `items` | `array` | 時系列データ（古い順、件数は可変） |
| `items[].time` | `string` | 計測時刻（JST） |
| `items[].estimated_wait_minutes` | `number` | その時刻の推定待ち時間（分） |

フロントエンドは、固定のデータ件数や時間間隔を前提にしない。

- `items[].time` の日付部分は使用せず、時刻部分を0分から1440分までの値へ変換してX軸に使用する
- `items[].estimated_wait_minutes` をY軸に使用する
- X軸は集計期間にかかわらず0:00から24:00までを表示範囲とする
- コンテナ幅に追従するレスポンシブ表示とする

## 状態およびエラー表示

- 初回取得中はローディング表示を行う
- 初回取得に失敗した場合はエラーメッセージと再読み込みボタンを表示する
- 現在の待ち時間の定期更新に失敗した場合は、直前に取得できたデータを維持して警告を表示する
- グラフの `items` が空の場合は「表示できる待ち時間データがありません」と表示する

## グラフ実装方針

React向けグラフライブラリとして広く利用されており、レスポンシブ表示、時刻軸、ツールチップを実装できる `Recharts` を使用する。

- グラフ種別: 折れ線グラフ
- X軸: 時刻（連続値として扱い、データ間隔の差を表示へ反映する）
- Y軸: 推定待ち時間（分）
- ツールチップ: 計測時刻と推定待ち時間を表示する
- レスポンシブ対応: `ResponsiveContainer` を使用する

## 今後追加するテスト項目

現時点ではモックおよびフロントエンドテストを実装しない。テスト基盤を追加する際は、少なくとも次のモックデータを用意する。

- 現在の待ち時間とグラフデータを正常に取得できる場合
- `estimated_wait_minutes` が `null` の場合
- グラフの `items` が空の場合
- 初回のAPI通信に失敗する場合
- 現在の待ち時間の定期更新に失敗する場合
