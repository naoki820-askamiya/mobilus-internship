# 待ち時間時系列 API 仕様書

取得日の前日8:00〜18:00の推定待ち時間を1時間単位で返し、フロントエンドの待ち時間グラフ表示に使用する。

---

## 1. API 契約

| 項目 | 内容 |
|------|------|
| メソッド / パス | `GET /api/wait-time/hourly` |
| 認証 | 不要（エンドユーザ向け公開 API） |
| 成功時ステータス | `200 OK` |
| Content-Type | `application/json` |

### リクエスト

クエリパラメータおよびリクエストボディは使用しない。

### レスポンス

```json

  "items": [

    },
    {
      "time": "2026-08-16 09:00:00",
      "estimated_wait_minutes": 8
    },
    {
      "time": "2026-08-16 10:00:00",
      "estimated_wait_minutes": 12
    },
    {
      "time": "2026-08-16 11:00:00",
      "estimated_wait_minutes": 15
    },
    {
      "time": "2026-08-16 12:00:00",
      "estimated_wait_minutes": 10
    },
    {
      "time": "2026-08-16 13:00:00",
      "estimated_wait_minutes": 5
    },
    {
      "time": "2026-08-16 14:00:00",
      "estimated_wait_minutes": 4
    },
    {
      "time": "2026-08-16 15:00:00",
      "estimated_wait_minutes": 6
    },
    {
      "time": "2026-08-16 16:00:00",
      "estimated_wait_minutes": 12
    },
    {
      "time": "2026-08-16 17:00:00",
      "estimated_wait_minutes": 9
    },
    {
      "time": "2026-08-16 18:00:00",
      "estimated_wait_minutes": 3
    }
  ]
}
```

| フィールド | 型 | 必須 | 説明 |
|------------|-----|------|------|
| `updated_at` | `string` | 必須 | レスポンス生成時刻。グラフの「現在時刻線」に使用する |
| `items` | `array` | 必須 | 取得日の前日8:00〜18:00の時系列。古い順に11件を返す |
| `items[].time` | `string` | 必須 | 対象バケットの開始時刻（正時） |
| `items[].estimated_wait_minutes` | `number` | 必須 | 対象時間帯の推定待ち時間（分） |

`updated_at` と `items[].time` は、既存の待ち時間 API と同じ `YYYY-MM-DD HH:MM:SS` 形式のJST文字列とする。

---

## 2. 時系列の生成ルール

- `updated_at` の日付を取得日とし、その前日を時系列の対象日とする。
- 対象日の8:00から18:00まで、両端を含めて1時間刻みで合計11件を返す。
- `items` は最古のバケットから最新のバケットへ昇順に並べる。
- 各 `items[].time` は分・秒を `00:00` に切り下げた正時とする。
- 9:00〜12:00および16:00〜17:00をピークタイムとし、通常時間帯より待ち時間が長いモック値を設定する。
- ピークタイムは開始時刻と終了時刻を含む。

例として `updated_at` が `2026-08-17 18:30:00` の場合、対象範囲は次のとおり。

- 最古: `2026-08-16 08:00:00`
- 最新: `2026-08-16 18:00:00`
- 件数: 11件
- ピークタイム: `09:00`〜`12:00`、`16:00`〜`17:00`

---

## 3. フロントエンドでの利用

- X軸には `items[].time` を使用する。
- Y軸には `items[].estimated_wait_minutes` を使用する。
- 現在時刻を示す縦線には `updated_at` を使用する。
- 配列は古い順で返るため、フロントエンド側での並べ替えは不要とする。

---

## 4. 受け入れ条件

- `GET /api/wait-time/hourly` が `200 OK` を返す。
- `items` の要素数が常に11件である。
- `items` が `time` の昇順である。
- 隣接する `items[].time` の間隔が1時間である。
- すべての `items[].time` が正時である。
- 最古の `items[].time` が取得日前日の8:00、最新が同日18:00である。
- 9:00〜12:00および16:00〜17:00の待ち時間が通常時間帯より長く設定されている。
- `estimated_wait_minutes` が分単位の数値である。
